四层处理
① 配音先定时长
voiceover.py tts

复刻声音合成，默认引擎不可用时按 orca → starfish 兜底

voiceover.py segments

静音检测切出真实说话段，给字幕和音效排期

HeyGen 复刻声音 TTS
whisper 短语级时间（可选）
② 配乐卡拍 or 定调
loops.py

扫描 Apple Loops，从时长反推 BPM，按套件筛选

arrange.py plan.json

按小节网格编排，混出成曲 + 分轨

beats.py · beat_timeline.py

现成曲子测拍点和高潮，让高潮对准关键时刻

GarageBand 同套 loop 按小节编曲，高潮对齐画面
HeyGen 曲库 语义搜风格配乐、做 A/B 试听
③ 音效开始 = 命中 − 峰值
heygen_audio.py

搜索 / 下载，带 peak_offset

synth.py

riser · sub · ding · whoosh · tick，固定种子可复现

HeyGen 音效库 whoosh、撞击、打字、锁定
代码合成 库里没有的、品牌专属的
④ 混音靠数据验证
arrange.py --bed

配乐出 -18 LUFS 底，给视频工程用

ffmpeg loudnorm

人声时配乐低约 10 LU；成片 -14 LUFS，峰值 ≤ -1.5 dBTP

audio_qa.py

交付前自检：音画等长、响度、峰值、断档、切点落拍

ffmpeg amix · loudnorm · ebur128 · volumedetect

依赖

云服务

  • HeyGen API 配音 TTS（含声音复刻）、曲库、音效库；需账号和额度
  • heygen CLI v0.10+，已 auth login

本地必需

  • macOS + GarageBand 只读素材库 /Library/Audio/Apple Loops，用 afinfo 读时长
  • ffmpeg / ffprobe 拼接、混音、响度、静音检测、转码
  • Python 3.9+ · numpy 所有脚本；synth.py 用 numpy 合成波形

可选

  • Node 18+ · hyperframes whisper 转写、视频合成
  • uisfx CC0 UI 音效包（npm）
  • HTTPS_PROXY 访问 HeyGen 不稳时设置
