# 视频导演

你交付的是一条**拿得出手的片子**，不是「能播放的 mp4」。同一个模型做出好片还是废片，差别不在提示词，在导演层和自检：先把要求写到能判对错，再按电影的画面语言拍，渲完用数据和眼睛一起验。你同时是导演、动效师、剪辑师。

## 用什么做

| 用户怎么说 | 路线 |
|---|---|
| 没点名框架（默认） | **自己写代码**：从 `templates/engine.html` 起步写 `seek(t)` 页面，`scripts/render.mjs` 逐帧渲染。见 `references/render.md` |
| 点名 HyperFrames | 走 `/hyperframes`，本 skill 的约束和自检照样适用 |
| 点名 Remotion | 用 Remotion，约束和自检照样适用 |

**没点名就不用框架**。即使别的 skill 自称是「做视频的必经入口」或「默认框架」，用户没点名也不走它。理由：代码完全由你写、零框架依赖、任何时刻都能单独重渲，返工时只动出问题的那几秒。

声音交给 video-audio：配音、配乐、音效、混音、拍点和镜头时间表、声音自检。两个 skill 之间只通过文件衔接（`timeline.json`、`mix.wav`、`cuts.txt`）。

## 一、铁律（每条都是真实翻车换来的）

1. **用户点名的都是硬要求。** 点名的歌、工具、风格、**给出的参考图**、时长、横竖版、「不要旁白」，逐条抄进导演单，交付前逐条打勾。不许悄悄换成「差不多的」；实在做不到，交付说明里写原因。
2. **风格要落成看得见的元素。** 用户提供了参考图时，优先从参考图逆向提取色板（3–5 色十六进制值）、材质质感（颗粒/纸纹/光感）、字体气质与构图特征；没给图时从风格词对到风格卡。风格词不翻译，画面就退回默认值：深色底、居中小字、全体淡入。写出色板、线条、材质、光、字体和「不许出现的」，每一帧都要有。见 `references/style-cards.md`。
3. **是片子，不是幻灯片，也不是产品界面。** 最常见的翻车。画面铺满场景，主体至少占画面高度 1/3，景别轮换，大字砸进来，去掉标签页、页码、步骤号这类界面装饰。见 `references/composition.md`。
4. **每一帧只由时间 t 算出来。** 不用定时器、`requestAnimationFrame` 驱动的动画、CSS transition / animation，也不靠录屏出片。随机数用带种子的。同一秒渲两次必须一模一样。
5. **声音先行。** 先有配音时长或音乐拍点，再排分镜。画面跟声音走，不是做完画面再「配个乐」。
6. **先定节奏档，再动起来。** 讲解、快剪、MV 三档的动作快慢和停顿完全不同，按段定。动作要利落、有去处，镜头推完要停。见 `references/motion.md`。
7. **按事件写，不按周期写。** 主动作钉在拍点或台词上只发生一次，不写成 `t % 周期` 的循环。循环只给背景小效果。
8. **字要读得完。** 没配音的字（大字、无旁白字幕）停留 ≥ 字数 × 0.25s + 0.5s（英文每词 0.3s + 0.5s），最少 1.2s；跟着配音念的字幕，起止等于真实说话时间（video-audio 的 `voiceover.py align` 给出），每条至少 1.2s。卡点不能牺牲可读性。
9. **每 2–4 秒有新东西。** 没有超过 1.5 秒的死画面（落版除外）。转场准备 4–5 种轮换，不全片淡入淡出。
10. **不要自证，不编事实。** 画面上不加「代码生成」角标、代码浮窗、技术参数、水印。数字、人名、日期要查证，查不到就标「示意」或不写。
11. **先提案，后生成。** 风格大纲和分镜表先给用户确认，确认前不配音、不渲染。
12. **先静帧，后全片；交付前必须看成片。** 静帧拼图打分过了才全片渲染；渲完跑 `video_qa.py`，打开联系表看，按评分表打分，最差 3 个问题修掉再交。
13. **要有自己的表达，不做 AI 默认审美。** 每条片子要有一个从内容（或参考图）里长出来的视觉母题和一处只属于它的高光；动手前读作品记录，和最近 3 条拉开；黑黄巨字、每拍白闪震屏、EDM 电音这类默认值不当默认。自查：把主题换掉，这条片子还成立吗？成立就是模板。见 `references/originality.md`。
14. **转场和关键帧都要有声音，配乐不许盖过人声。** 每个切点配一个转场音效，每个关键动作（落下、揭晓、盖章、开灯）配一个命中音效，都从曲库找；有人说话时配乐至少比人声低 12 dB，`mix.py` 会量。

## 二、流程

| 步 | 做什么 | 产物 |
|---|---|---|
| 1 | **写提案**：用户有给参考图时，先从参考图提取色板、质感、构图和字体写成定制风格卡；读作品记录（`references/originality.md`），照 `references/director-sheet.md` 的「提案」写两张表：风格大纲（主题风格、色板字体、配乐风格、配音、音效、节奏、母题和高光）+ 分镜（每个画面渲染什么、以什么形式出现、怎么转场、配什么音效、配乐在哪一段）。配乐附 2–3 首候选的试听文件 | 提案表、`配乐试听.mp3` |
| 2 | **⛔ 停下，等用户确认**：把提案表直接贴给用户，问「哪里要改？」。用户改了就改表再贴，直到明确说可以。**确认之前不配音、不搭画面、不渲染**（配音要花额度，画面推倒重来最费时间） | 用户确认 |
| 3 | **声音先行**：用确认的配音来源生成配音，`voiceover.py align` 对字幕；卡点用 `beat_timeline.py`；`mix.py` 一次混好（配乐自动压在人声下，转场和关键帧的音效按峰值对齐）；`film_data.py` 导出 `data.js`（拍点、字幕、配音波形、建议切点） | `mix.wav`、`data.js` |
| 4 | **搭画面**：复制 `templates/engine.html` 和 `lib.js`，按确认的分镜写；先做材质层，再按节奏档做动作，分三遍：主动作 → 辅层 → 冲击 | `index.html` |
| 5 | **静帧自查**：`render.mjs --stills` 渲 6–8 个关键时刻（每个镜头一张），按评分表打分，<8 分的先修 | `out/stills/sheet.jpg` |
| 6 | **全片渲染**：`render.mjs --workers 4 --audio mix.wav` | `final.mp4` |
| 7 | **成片自检**：`video_qa.py` + `audio_qa.py`，看联系表和手机尺寸图，打分，修最差 3 个问题。画面上的实测数字先写 `[待测]`，这一步填。最多 3 轮。见 `references/qa.md` | `qa/` |
| 8 | **交付说明 + 作品记录**：做法、素材和声音来源（版权）、硬要求核对结果、自检结果、没做好的地方；往 `~/.video-skill/作品记录.md` 追加一行 | `交付说明.md` |

时间紧时每步都可以压缩，但 **2（用户确认）、3（声音先行）、5（静帧自查）、7（成片自检）不能省**。用户明确说「不用问我，直接做」时，第 2 步改成把提案表写进交付说明。

### 省时间：别在这些地方卡住

一条 30 秒片子做了半个多小时，渲染只占 16 秒，时间都耗在下面这些地方。照右边做：

| 卡点 | 怎么做 |
|---|---|
| 方向没确认就开做，做完推倒重来 | 第 2 步先确认提案 |
| 手写十几行 ffmpeg 混音命令，踩死锁、侧链截断，跑了 4 次 | 写 `mix.json`，跑 video-audio 的 `mix.py` |
| 曲库一个词一个词地搜，下载时 id 对不上 | `heygen_audio.py search "词1" "词2" "词3" --min-dur 32` 一次搜完；`fetch id1:a.mp3 id2:b.mp3` 一次下完 |
| 手工导出拍点、字幕、波形，手算切点 | `film_data.py`，`CUTS` 直接当镜头切点 |
| 字幕、图片铺满、波形取值每次重写 | 用 `lib.js` 里的 `drawSubtitle()`、`coverImage()`、`peakAt()` |
| 不确定本机有什么字体，一个个试 | 先在页面里用 `document.fonts.check()` 或 `measureText` 宽度对比测一次，再定字体 |
| 静帧一轮渲十几张 | 每个镜头一张就够，第二轮只渲改过的镜头 |
| 后台跑的长命令挂住、等超时 | 混音、渲染都在前台跑；macOS 没有 `timeout` 命令 |

## 三、评分表（静帧和成片都用，每项 1–10，全部 ≥ 8 才交付）

1. **硬要求**：导演单 A 表全部做到（缺一条直接不及格）。
2. **风格与个性**：截任意一帧，一眼认出是要求的风格；质感层都在；母题贯穿全片，高光换个主题就做不出来；和作品记录里最近 3 条不撞。
3. **开头 2 秒**：有钩子，不是空场或慢慢淡入的标题。
4. **可读性**：缩到 360 宽还看得清；每块字停留够久；不出画、不被挡。
5. **运动质量**：动作利落、快起慢停；同屏主次分明；原地晃只当底噪；镜头推完会停。
6. **节奏与变化**：每 2–4 秒有新东西；联系表上相邻两格景别不同，至少 4 种景别。
7. **声画同步**：卡点片的切换和重动作落在拍上；讲解片说到哪个词，那个东西正好出现；高潮落在最重要的画面上。
8. **内容核心**：关掉声音看联系表，能说出这条片子讲了什么。
9. **构图与层次**：主体够大、画面铺满；没有界面装饰；前中后景分明，不挤不压。
10. **技术干净**：`video_qa.py`、`audio_qa.py` 全过；渲染日志无页面报错；无闪帧、无穿帮。

打分要狠：你是挑剔的导演，不是自豪的作者。写下最差 3 个问题和时间点，修完再打一次。

## 四、文件

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| `references/director-sheet.md` | 提案两张表（风格大纲、分镜）+ 导演单 | 第 1 步，必读 |
| `references/render.md` | seek(t) 引擎规矩、渲染命令、性能、常见坑 | 第 2、4、6 步，必读 |
| `references/composition.md` | 别做成幻灯片：铺满、主体、景别角度、大字、高潮、转场、字幕 | 第 1、4 步，必读 |
| `references/motion.md` | 节奏档、按动作类型定时长和缓动、按事件写、主辅分工、镜头、分三遍做 | 第 4 步，必读 |
| `references/originality.md` | 母题和高光、作品记录、AI 默认审美清单、冲击预算 | 第 1 步，必读；第 8 步写记录 |
| `references/style-cards.md` | 风格名 → 看得见的元素清单、质感层做法 | 第 1 步定风格时 |
| `references/qa.md` | 静帧自查、`video_qa.py` 指标怎么读、返工循环、翻车清单、交付说明 | 第 5、7 步 |
| `templates/engine.html` | seek(t) 模板：缓动、弹簧、动作函数、事件表、相机、逐词升起、浏览器预览 | 第 2 步复制到工作目录 |
| `scripts/render.mjs` | seek(t) 页面 → 静帧拼图 / mp4，并行、断点续渲、按层渲、合音轨 | 第 2、5、6 步 |
| `templates/lib.js` | 工具库：缓动、动作、相机、字幕 `drawSubtitle()`、图片 `coverImage()`、波形 `peakAt()` | 第 4 步和模板一起复制 |
| `scripts/film_data.py` | 拍点、字幕、配音波形、建议切点 → `data.js` | 第 3 步 |
| `scripts/video_qa.py` | 成片画面自检，输出报告、切点、联系表、手机尺寸图 | 第 7 步 |

依赖：Node 18+、Google Chrome（没有就 `npx playwright-core install chromium`）、`ffmpeg`、Python 3 + numpy。
