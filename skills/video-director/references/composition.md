# 构图、景别、转场、文字：别做成幻灯片

代码做视频，最容易带出「做网页」的习惯：每个镜头同一个版式（左上标题、中间一张小图、四周小标签），深色空底，主体很小，带页码和标签页。下面每条都能在静帧上核对，`video_qa.py` 的「画面空不空」「版式雷同」「每秒变化」专门抓这类问题。

## 1. 画面铺满，主体够大

- 每个镜头是一个完整的场景：布景、道具、光、纹理。不是空底上摆卡片。
- **主体至少占画面高度 1/3**，特写时占满画面。空底上放一张小图，是最常见的失败构图。
- 颜色按风格给足饱和度和对比度，别默认浅灰淡蓝或「深色底配小字」。
- 纯色大底只给动态排版的快切用（这时 `video_qa.py` 加 `--allow-solid-bg`）。
- 去掉界面装饰：标签页、导航条、页码、页眉、「① ② ③」步骤徽章、面包屑、日期戳。
- 讲解片别用「左文右图」的固定版式：道理靠物体的动作演出来。说「连线」，就让线一条条画出来连上；说「把概念变成物体」，就让一块积木被推进机器。数字要「长」出来（滚动计数、柱子生长），并且和动作发生在同一个镜头里。

## 2. 景别和角度（分镜里每个镜头都写）

| 景别 | 画面里有什么 | 用在哪 |
|---|---|---|
| 大特写 | 一只眼睛、一行关键数字、一个按钮 | 钩子、紧张、高潮前一拍 |
| 特写 | 一张脸、一个物体占满画面 | 情绪、强调、结果 |
| 中景 | 上半身或一组物体 | 动作、演示 |
| 全景 | 全身 + 环境 | 交代空间、行动开始 |
| 远景 / 鸟瞰 | 整个场景、地图全图 | 开场、转场、收尾 |

- 全片至少 4 种景别，**相邻两个镜头景别不同**。节奏越紧，景别跳得越大（全景 → 大特写）。
- 角度至少 2 种：平视、俯拍、低角度仰拍、过肩、主观视角。
- 同一张底图（地图、界面）再次出现时，换景别、换焦点、换光。原地踏步最显眼。
- 三分法：主体放在三分线上，视线方向留出空间；文字和主体分在两边，不叠在一起。

## 3. 大字和高潮

- 标题、金句的字宽至少占画面宽度 1/3，**砸进来**（放大回弹 + 一个重拍），不是左下角小字淡入。
- 同一时刻屏幕上只有一句大字。
- 高潮（反转、碎裂、亮相、logo）给足：大特写 + 慢放或定格 + 最重的那一拍，前面留一拍安静做铺垫。
- 用户点名的画面类型要真画出来，不能用一张照片或一行字顶替。

## 4. 转场：准备 4–5 种轮换

| 转场 | 做法 | 适合 |
|---|---|---|
| 形状接形状 | 上一镜的圆、气泡、徽章放大铺满，成为下一镜的底 | 品牌片、信息图 |
| 颜色铺满 | 从某个物体扩出一个圆，0.3s 铺满，再收进下一镜的物体 | 卡点高潮 |
| 甩镜头 | 快速横移 + 运动模糊，下一镜从反方向甩进来 | 动作、紧张段 |
| 遮罩擦除 | 撕纸、墨迹、卷轴、百叶窗擦过 | 绘本、国风、地图 |
| 物体穿过镜头 | 前景物体飞过挡住画面，过去后已经换景 | 科普、绘本 |
| 匹配剪辑 | 上下两镜的主体在同一位置、同一形状 | 叙事 |
| 硬切 | 只在拍点上用，配一个冲击（缩放弹跳、闪一下颜色） | 卡点段 |

闪白最多用一次，不拿来遮转场。转场要接得上：上一镜怎么出去，下一镜就顺着那个方向和速度进来（往左甩出，就从右边甩进）。甩镜头用模板的 `whip()`，配方向模糊。

**卡点片的切换本身就是卡点**：高能段每 1–2 拍硬切一刀；20 秒的卡点片至少 10 刀。靠叠化慢慢过渡不算卡点。

## 5. 字幕和文字动画

- 字幕底部居中，最多两行，单行不超过 16 个汉字；带半透明底条或描边，任何画面上都读得清。竖版注意避开平台 UI 遮挡区。
- 跟着配音念的字幕：文字和念的完全一致，起止直接用 video-audio 的 `voiceover.py align` 输出的 `cues.json`，每条至少 1.2s。
- 没配音的字（大字、无旁白字幕、对话气泡）：停留 ≥ 字数 × 0.25s + 0.5s（英文每词 0.3s + 0.5s），最少 1.2s。
- 所有字离画面边缘至少 6%（安全区）。
- 大字逐词遮罩升起，每词错开 40–60ms；重点词换色、加粗，或晚 0.1s 单独砸下。
- 退场比进场快：进 0.4–0.6s，出 0.2–0.3s。
- 缩到 360 宽还要读得清，`video_qa.py` 的手机尺寸图专门看这个。
