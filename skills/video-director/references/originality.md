# 个性化表达：别让片子趋于雷同

模型最大的惯性是「上次这么做没出错，这次还这么做」。每一条单看都合格，放在一起就是同一个模板换了文字：黑黄配色、超大黑体砸字、每个重拍白闪加震屏加碎片、EDM 配 808 和品牌叮、「一句话」「一条龙」这类套话。这就是 AI Slop。

自查只有一个问题：**把主题换成别的项目，这条片子还成立吗？** 成立，就是模板，不是作品。

## 1. 每条片子必须有的三样（写进导演单 B7）

1. **一个从内容里长出来的视觉母题**。去主题本身找，不去模板里找。讲声音工具，母题可以是「声波被剪刀剪成一格格胶片」；讲数据库，可以是「抽屉」；讲协作，可以是「两只手传接一张纸」。母题贯穿全片，转场和高潮都从它变出来。
2. **一处只属于这条片子的高光**：换个主题就做不出来的那一下。写清楚在第几秒、发生什么。
3. **文案用真东西**：项目里真实的命令、文件名、数字、截图、用户原话。少用口号（「一站式」「一条龙」「赋能」「只需一句话」）。

## 2. 作品记录：动手前读，交付后写

位置：`~/.video-skill/作品记录.md`，所有项目共用。文件不存在就新建。

**动手前**读最近 3 条。下面 6 项里，至少 4 项要和每一条都不同：风格、主色板、主字体、开场方式、配乐曲风、收尾方式。撞了就换，在导演单里写清换成了什么。

**交付后**追加一行：

```
| 日期 | 片名 | 风格 | 主色板 | 主字体 | 开场 | 配乐曲风 / 来源 | 收尾 | 母题 | 高光 |
```

## 3. AI 默认审美清单（默认不用，用就在导演单里写理由）

| 默认会做 | 换个思路 |
|---|---|
| 黑底或黄底 + 超大黑体砸字，一屏一个词 | 先定母题，字服从画面；字体跟内容气质走（宋体、手写、等宽、衬线都可以） |
| 每个重拍都白闪 + 震屏 + 碎片 | **重冲击全片最多 2 次**，其余的拍点用切镜、换景别、物体动作、留白来落 |
| 霓虹渐变、玻璃拟态卡片、发光描边 | 一种真实的材质（纸、布、金属、胶片、木头）做到位 |
| 居中大标题 + 灰色副标题 | 不对称构图，主体和字分开两边 |
| 三张并排的「卖点卡片」 | 把卖点演成三个动作或三个场景 |
| EDM + riser + 808 下坠 + 品牌叮 | 曲风从内容出发，见 video-audio 的「别让声音趋于雷同」 |
| 结尾 logo 砸下 + 安装命令条 | 收尾回到母题，让开头埋的东西在结尾有个回应 |

清单里的东西不是禁止，是不能当默认值。用户点名要、或者内容确实需要时照用。

## 4. 风格卡怎么用

风格卡是起点，不是答案。同一张卡连续两条片子用，第二条至少换掉一半的元素（色板、字体、材质、开场）。对不上任何一张卡的风格，反而更容易做出个性，照格式自己写一张。
