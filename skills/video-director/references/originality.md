# 个性化表达：别让片子趋于雷同

模型最大的惯性是「上次这么做没出错，这次还这么做」。每一条单看都合格，放在一起就是同一个模板换了文字：黑黄配色、超大黑体砸字、每个重拍白闪加震屏加碎片、EDM 配 808 和品牌叮、「一句话」「一条龙」这类套话。这就是 AI Slop。

**更隐蔽的一种**：躲开了旧套路，又躲进一个新的安全区。本 skill 自己就踩过：禁掉霓虹和玻璃以后，作品记录里连着三条是胶片剪辑台、奶油纸杂志、旧报纸讣告，宋体和打字机字体反复出现。每条的母题都不同，审美却是一家。只禁止、不给发散方法，模型就会找到唯一的新默认。所以这里不给「换成什么」的标准答案，给的是**发散的方法**和**拉开的检查**。

自查只有一个问题：**把主题换成别的项目，这条片子还成立吗？** 成立，就是模板，不是作品。

## 1. 视觉家族：先在大方向上拉开

| 家族 | 有什么 | 典型人格（见 `motion.md` 第 0 节） | 风格卡 |
|---|---|---|---|
| **物质手作** | 纸、布、黏土、木头、胶片、印刷品，看得见的手工痕迹 | 弹性卡通、电影慢镜 | 5 撕纸、6 墨线、7 地图、8 国风 |
| **编辑排版** | 网格、巨型字、杂志版式，字本身就是画面 | 机械硬切、精密克制 | 1 动态排版、9 瑞士网格 |
| **电影摄影** | 写实画面、真实光影、景深、颗粒、宽银幕比例 | 电影慢镜 | 10 电影感 |
| **数字生成** | 着色器、粒子、流场、程序化图形、数据艺术 | 流体有机 | 11 生成流体 |
| **空间三维** | 等轴、Three.js、物体在空间里转、镜头在空间里穿行 | 精密克制、流体有机 | 3 等轴、12 空间产品 |
| **界面产品** | 真产品界面、真录屏，被精密地摆进画面 | 精密克制、机械硬切 | 2 发布会、4 玻璃 |
| **插画角色** | 扁平、赛璐璐、Q 版角色，靠角色表演讲道理 | 弹性卡通 | 照格式自写 |

- 提案里的 **3 个概念必须来自 3 个不同家族**。三个都是物质手作的不同变体（报纸、胶片、木桌），不算发散。
- 新片的家族和作品记录最近 2 条都不同。用户点名了风格，或内容确实需要（讲老照片修复，就该是物质手作），在导演单写理由。

## 2. 三个概念怎么想出来

每个概念 = **一句话的大创意**（这条片子把主题看成什么）+ 家族 + 运动人格 + 母题 + 高光。从三个不同的源头各想一个：

1. **物件隐喻**：主题里本来就有的一个实物或场景。讲音频工具 → 一条胶片的光学声带；讲数据库 → 一面抽屉墙。
2. **过程隐喻**：主题**做的那件事**的动态。讲音频工具 → 声音像水流被引导进河道；讲构建系统 → 零件在流水线上被拼起来。适合流体有机、空间三维。
3. **反差隐喻**：借一个毫不相干领域的视角。讲代码库 → 一座城市的夜间航拍；讲声音 → 天气预报。最容易出意外的好东西，也最容易牵强，要看它能不能撑起全片的转场和高潮。

三个概念想完，做一个**拉开检查**：把三个样片各截一帧，盖住文字摆在一起。看着像同一个人做的，就重想最像的那个。

## 3. 每条片子必须有的三样（写进导演单 B7）

1. **一个从内容里长出来的视觉母题**。去主题本身找，不去模板里找。母题贯穿全片，转场和高潮都从它变出来。
2. **一处只属于这条片子的高光**：换个主题就做不出来的那一下。写清楚在第几秒、发生什么。
3. **文案用真东西**：项目里真实的命令、文件名、数字、截图、用户原话。少用口号（「一站式」「一条龙」「赋能」「只需一句话」）。

## 4. 作品记录：动手前读，交付后写

位置：`~/.video-skill/作品记录.md`，所有项目共用。文件不存在就新建；旧表没有「家族」「运动人格」两列就补上。

**动手前**读最近 3 条。家族、运动人格和最近 2 条都不同；风格、主色板、主字体、开场方式、配乐曲风、收尾方式这 6 项，至少 4 项和最近 3 条都不同。撞了就换，在导演单里写清换成了什么。

**交付后**追加一行：

```
| 日期 | 片名 | 家族 | 运动人格 | 风格 | 主色板 | 主字体 | 开场 | 配乐曲风 / 来源 | 收尾 | 母题 | 高光 |
```

## 5. 默认审美清单（默认不用，用就在导演单里写理由）

| 默认会做 | 为什么是默认 | 怎么破 |
|---|---|---|
| 黑底或黄底 + 超大黑体砸字，一屏一个词 | 「有冲击力」的最短路径 | 先定概念和家族，字服从画面 |
| 每个重拍都白闪 + 震屏 + 碎片 | 数据上热闹 | 重冲击全片最多 2 次；先看运动人格允不允许冲击 |
| 霓虹渐变、玻璃拟态卡片、发光描边 | 「科技感」的最短路径 | 回到概念：这个主题的光从哪来、照在什么上 |
| **复古纸感 + 宋体 + 打字机字 + 印章 + 胶片颗粒** | 躲开上面三条以后的新安全区（本 skill 2026-10 连续三条都是） | 只在内容确实是旧物、档案、手作时用；否则换家族 |
| 居中大标题 + 灰色副标题 | 网页 hero 区的习惯 | 不对称构图，主体和字分开两边；或者字就是画面（编辑排版） |
| 三张并排的「卖点卡片」 | 网页功能区的习惯 | 把卖点演成三个动作或三个场景 |
| 所有动作都弹一下（`outBack`、预备、压扁） | 「有活力」的最短路径 | 那是弹性卡通一种人格；先选人格 |
| EDM + riser + 808 下坠 + 品牌叮 | 「宣传片配乐」的最短路径 | 曲风从内容出发，见 video-audio 的「别让声音趋于雷同」 |
| 结尾 logo 砸下 + 安装命令条 | 落版的最短路径 | 收尾回到母题，让开头埋的东西在结尾有个回应 |

清单里的东西不是禁止，是不能当默认值。用户点名要、或者内容确实需要时照用。

## 6. 风格卡怎么用

风格卡是起点，不是答案。同一张卡连续两条片子用，第二条至少换掉一半的元素（色板、字体、材质、开场）。对不上任何一张卡的概念，反而更容易做出个性，照格式自己写一张。
