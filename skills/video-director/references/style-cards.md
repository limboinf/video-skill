# 风格卡：把风格名翻译成看得见的元素

用户给的风格词，先对到最接近的一张卡；对不上就照同样的格式自己写一张，写进导演单 B1。**如果用户给了一张或多张参考图**，优先从参考图提炼出一张定制风格卡（见下文 0）。

**风格卡是起点，不是答案。** 用户没指定风格时，别默认第 1 张；提案的 3 个概念要来自 3 个不同的视觉家族（见 `originality.md` 第 1 节），每张卡标题后面标了家族和常配的运动人格。同一张卡连续两条片子用，第二条至少换掉一半元素。每张卡四行：**定义（有什么、没有什么）→ 元素 → 做法 → 做偏**。「做偏」最重要：不写清楚，模型最可能退回到那个样子。

---

### 0. 用户提供参考图时：从参考图提炼定制风格卡
- **定义**：参考图的核心视觉主题与气质（如高对比机能风、复古纸质绘本、极简瑞士排版、胶片质感等）。
- **元素**：
  - 吸取 3–5 种核心色（十六进制色值，明确标注底色、主体色、辅色、高光点缀色）；
  - 提取质感层：识别是纸纹、胶片颗粒、复古噪点、微光描边、毛玻璃还是等轴投影；
  - 提取字体与排版气质：字重（粗黑/细线）、衬线/无衬线、版式留白节奏；
  - 提取图形母题：将参考图中的特征几何形状或视觉符号作为贯穿全片的视觉母题。
- **做法**：底层统一铺设提取出的质感层，主体与文字严格按吸取的色板与字体风格渲染，确保动起来后依然承袭参考图的美学。
- **做偏**：只吸取了单调色块却丢了质感层；退化成黑底悬浮卡片；未保留参考图的留白与版式密度。

### 1. 动态排版产品宣传片 · 编辑排版 · 机械硬切 / 弹性卡通
- 定义：超大粗黑体短句一句句砸出来，纯色大底快切，穿插产品真界面和操作演示，落版 logo 加安装命令。
- 元素：品牌主色 / 米白 / 纯黑三种大底轮换；粗黑体，句尾可带品牌色圆点；斜飞入的界面卡片；可见的鼠标点选、打字。
- 做法：逐词遮罩升起；界面用真截图或真录屏；切换卡拍点。`video_qa.py` 加 `--allow-solid-bg`。
- 做偏：居中小字配渐变；界面是编的；一屏塞三四张小卡片；节奏拖沓。

### 2. 深色科技发布会（口播包装） · 界面产品 · 机械硬切
- 定义：黑底配一个荧光强调色，口播人像在全屏、小窗之间切换，讲概念时整屏换成解释动画。
- 元素：纯黑底；荧光黄绿或品牌色；便利贴、贴纸式标签；全程字幕。
- 做法：口播视频当主轨，解释段整屏动画；贴纸跟着口播的词逐个弹出。
- 做偏：全程小窗或全程全屏；动画和口播的词对不上；黑底上只有一张小卡片（`video_qa.py` 报「画面空」）。

### 3. 2.5D 等轴科技插画 · 空间三维 · 弹性卡通 / 精密克制
- 定义：等轴视角的积木小世界，扁平小人在上面把道理演出来，画面上字很少。
- 元素：亮色底；蓝紫为主、橙黄绿点缀的积木（每块三个面三档明度）；几何小人；连线、光点。
- 做法：等轴投影 `x' = (x − y)·cos30°，y' = (x + y)·sin30° − z`；道理靠搭建、拆开、连线、发光演出来。
- 做偏：画面中央一座浅色孤岛，四周大片空底、小人很小。积木要铺到画面边缘，镜头推近到正在演示的角色。

### 4. 科技玻璃拟态 · 界面产品 · 精密克制
- 定义：深蓝底上的半透明毛玻璃卡片、发光细线，讲到哪个词就点亮哪个东西。
- 元素：深蓝渐变 + 细网格；毛玻璃卡片（模糊 + 白色细边 + 高光）；青色发光线；数据标签。
- 做法：`backdrop-filter`；元素按配音的说话段落点亮。
- 做偏：到处霓虹；卡片同时出现；卡片小、留白大。

### 5. 撕纸拼贴绘本 · 物质手作 · 弹性卡通
- 定义：彩色手工纸一层层贴上去，纸边带白色撕边，有纤维和投影；不是扁平矢量。
- 元素：高饱和纸色块；6–10 像素白色锯齿撕边；轻投影；纸纤维纹理；圆头 Q 版小人。
- 做法：形状 = 锯齿多边形 + 白边 + 投影 + 纸纹贴图；动起来像纸片被拉动（轻旋转、弹跳）。
- 做偏：没有白边和纸纹，就成了普通矢量卡通。

### 6. 手绘墨线卡通 · 物质手作 · 弹性卡通
- 定义：粗细变化的毛笔墨线、分层明暗、纸纹笔触；不是干净的扁平矢量。
- 元素：暖色纸底；黑褐色墨线（起笔细、中段粗、收笔细，偶有飞白）；平涂加一两档阴影；胶片颗粒和暗角。
- 做法：角色写成一个绘制函数，所有镜头复用，造型统一；纸纹、颗粒叠最上层。
- 做偏：线宽一致、没有纸纹；角色每个镜头长得不一样。

### 7. 复古地图纪录片 · 物质手作 · 电影慢镜
- 定义：摊在木桌上的泛黄地图当主线，红铅笔现场画路线，老照片头像卡出场。
- 元素：泛黄纸、等高线、指北针、红蓝箭头、印章；台灯暖光、折痕、颗粒；宋体或仿宋。
- 做法：路线按时间一笔画出来，画完沿线标注再逐个弹出；每次回到地图都换景别（全图 → 某个村镇 → 贴近笔尖）。
- 做偏：干净的现代信息图地图；路线整条一下子出现；每次回到地图都是同一个景别。

### 8. 国风手绘动画 · 物质手作 · 电影慢镜 / 流体有机
- 定义：颜料笔触、粗细不匀的墨线、水彩纸纹理，颜色素雅偏灰。
- 元素：低饱和青绿、赭石、墨色；云雾层次；远山、老树、小桥；留白。
- 做法：分层绘制 + 笔触纹理；季节用色调和天气粒子（花瓣、落叶、雪）。
- 做偏：颜色太鲜、太干净；变成三维游戏画面。

### 9. 瑞士网格排版 · 编辑排版 · 机械硬切
- 定义：严格网格上的无衬线大字、细线和数字，一个强调色；画面就是版面，没有插画、没有材质。
- 元素：白底或黑底 + 一个强调色（国际克莱因蓝、信号红、安全橙选一）；无衬线字一种字族两三个字重；12 栏网格、细分隔线、超大序号或数据。
- 做法：元素只沿网格跳位、换栏、换字号，切换卡拍；`perFrame` 写阶跃，不做弹跳；字号对比拉到 1:8 以上。
- 做偏：网格只是装饰线、元素不对齐；用了第二个强调色；加了投影、渐变、圆角卡片。

### 10. 电影感 · 电影摄影 · 电影慢镜
- 定义：像摄影机拍出来的画面：真实光源、景深、颗粒、宽银幕比例；字极少、很小、放在画面边缘。
- 元素：2.39:1 黑边或全画幅；低饱和、偏一个色温（冷青或暖琥珀）；浅景深前后景虚化；胶片颗粒、暗角、轻微光晕；衬线或细无衬线小字。
- 做法：素材用生图或授权照片，按分镜写好景别和机位；镜头慢推慢摇 + `defocus()` 拉焦；`render.mjs --sub 4 --shutter 180`；字用 `focusIn` 或 `wipe` 出现，停够再走。
- 做偏：照片平铺不动当幻灯片；字又大又居中；为了「电影感」只加黑边，光和景深没做。

### 11. 生成流体 · 数字生成 · 流体有机
- 定义：着色器算出来的流场、墨、丝、光，形态一直在缓慢变化；主题靠形态的变化讲，不靠图标和卡片。
- 元素：2–4 色的窄色板（一深一浅一点缀）；域扭曲噪声、流场粒子或等值线；高光只给最亮的一小撮；颗粒统一画面。
- 做法：从 `templates/shader.html` 起步，概念决定着色器（声音 → 波纹干涉；数据 → 粒子汇流；生长 → 分形扩散）；转场用形变、溶解，不切。
- 做偏：五颜六色的霓虹流体当屏保；流得太快（一秒挪动超过画面 5%）；形态和主题没关系，换个主题照样能用。

### 12. 空间产品 · 空间三维 · 精密克制
- 定义：产品或抽象物件在干净的空间里被一束光照着，镜头绕着它慢慢转，细节一个个被光扫出来。
- 元素：一个主物件（Three.js 建模，或产品真图做成卡片放进三维空间）；单一主光 + 一道轮廓光；深色或浅灰无缝背景；细小的标注线和数字。
- 做法：Three.js 每帧按 t 设相机（见 `render.md` 第 6 节）；镜头 `E.silk` 绕轴移动、推完停；标注用 `drawOn` 描线 + `wipe` 擦出；`--sub 4 --shutter 180`。
- 做偏：物件在画面中央原地自转一整段；三盏灯打得满屏平光；标注一下子全部出现。

## 质感层：让「代码画的」不显得廉价

代码画的东西显得廉价，通常是只有形状、没有质感。风格要求里提到的每一种质感，都要在静帧上看得到，缩到 360 宽还认得出。

| 质感 | 做法 |
|---|---|
| 纸纹 | 预生成一张噪声纹理（两三层不同尺度 + 稀疏短纤维），`multiply` 叠最上层，透明度 0.15–0.35 |
| 撕纸边 | 边缘带种子的随机锯齿（每 6–12 像素一个点，振幅 3–8 像素），外圈白边加投影 |
| 毛笔墨线 | 按速度改线宽，每段 ±0.6 像素抖动，偶尔留飞白 |
| 颗粒 / 胶片 | 按帧序号做种子撒细颗粒（仍然是确定的），加暗角 |
| 投影和体积 | 偏移的深色投影，或边上一条亮边（轮廓光） |
| 景深 | 每层定一个深度 z，`defocus(z, focus)` 算模糊像素；焦点随时间挪就是拉焦 |
| 光 | 一道光扫过 `sheen()` / `lightSweep()`；着色器里高光只给最亮的一小撮 |
| 运动模糊 | 不在页面里做，`render.mjs --sub 4 --shutter 180` 在渲染时做 |

颗粒、景深、光、运动模糊是电影摄影、生成流体、空间产品这几个家族的「质感」；纸纹、撕边、墨线是物质手作的。别把纸纹当成所有风格的通用高级感。

随机一律用带种子的随机数，并在时间轴外预先生成好。同一帧渲两次必须一模一样，返工时才能只重渲那几秒。

## 自己写风格卡

- 风格名用标准叫法（「撕纸拼贴」「赛璐璐」「等轴插画」），不自造词。
- 元素清单要能在静帧上逐条检查。
- 必写一条「做偏」。
- 知名角色、精细人物，代码画常被嫌简陋：优先三维现成模型或生图素材，除非用户点名纯代码。

## 概念预览：让用户看到「怎么动」再定

文字描述「暖白底 + 红蜡笔 + 宋体」，用户不一定能想象出实际效果；静态色板更看不出运动人格，而运动恰恰是高级和廉价的分水岭。所以每个概念出一份**概念预览**：上半是会动的样片，下半是色板、字体、质感和元素清单。

### 做法

每个概念一个目录 `concepts/A/`、`concepts/B/`、`concepts/C/`：

1. **样片 `motion.html`**：按概念的人格，从 `templates/engine.html`（弹性卡通、机械硬切）或 `templates/shader.html`（精密克制、电影慢镜、流体有机）复制，连同 `lib.js` 放进目录。只做**一个镜头、3–5 秒**：开场画面或高光那一下，母题必须出现，运动按选定人格写。不配音、不做辅层和冲击、不跑自检。
2. **预览页 `index.html`**：从 `templates/style-preview.html` 复制。改 `:root` 的色板、字体、质感变量；`#style-name` 写概念名、`#style-idea` 写一句话大创意、`#style-meta` 写家族和运动人格；`#motion` 的 iframe 默认指向同目录的 `motion.html`；填 `#palette`、`#type`、`#texture`、`#checklist`。
3. 用户在浏览器打开三个 `index.html` 对比。样片自动循环；点进 iframe 后按空格暂停，按 ← → 逐帧。

### 注意

- 三个概念来自三个家族、尽量三种人格。三份预览摆在一起像同一个人做的，就重想（见 `originality.md` 第 2 节）。
- 样片是**真代码**，选中的那个直接当第 4 步的起点继续写，不白做。
- 控制成本：每个样片别超过 15 分钟。画面细节做到「能看出这个概念成立」就停。
- 用户说「风格我定了」或只给了一个方向时，只出 1 份。
