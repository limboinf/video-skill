# 风格卡：把风格名翻译成看得见的元素

用户给的风格词，先对到最接近的一张卡；对不上就照同样的格式自己写一张，写进导演单 B1。**如果用户给了一张或多张参考图**，优先从参考图提炼出一张定制风格卡（见下文 0）。

**风格卡是起点，不是答案。** 用户没指定风格时，别默认第 1 张。同一张卡连续两条片子用，第二条至少换掉一半元素。见 `originality.md`。每张卡四行：**定义（有什么、没有什么）→ 元素 → 做法 → 做偏**。「做偏」最重要：不写清楚，模型最可能退回到那个样子。

---

### 0. 用户提供参考图时：从参考图提炼定制风格卡
- **定义**：参考图的核心视觉主题与气质（如高对比机能风、复古纸质绘本、极简瑞士排版、胶片质感等）。
- **元素**：
  - 吸取 3–5 种核心色（十六进制色值，明确标注底色、主体色、辅色、高光点缀色）；
  - 提取质感层：识别是纸纹、胶片颗粒、复古噪点、微光描边、毛玻璃还是等轴投影；
  - 提取字体与排版气质：字重（粗黑/细线）、衬线/无衬线、版式留白节奏；
  - 提取图形母题：将参考图中的特征几何形状或视觉符号作为贯穿全片的视觉母题。
- **做法**：底层统一铺设提取出的质感层，主体与文字严格按吸取的色板与字体风格渲染，确保动起来后依然承袭参考图的美学。
- **做偏**：只吸取了单调色块却丢了质感层；退化成黑底悬浮卡片；未保留参考图的留白与版式密度。

### 1. 动态排版产品宣传片
- 定义：超大粗黑体短句一句句砸出来，纯色大底快切，穿插产品真界面和操作演示，落版 logo 加安装命令。
- 元素：品牌主色 / 米白 / 纯黑三种大底轮换；粗黑体，句尾可带品牌色圆点；斜飞入的界面卡片；可见的鼠标点选、打字。
- 做法：逐词遮罩升起；界面用真截图或真录屏；切换卡拍点。`video_qa.py` 加 `--allow-solid-bg`。
- 做偏：居中小字配渐变；界面是编的；一屏塞三四张小卡片；节奏拖沓。

### 2. 深色科技发布会（口播包装）
- 定义：黑底配一个荧光强调色，口播人像在全屏、小窗之间切换，讲概念时整屏换成解释动画。
- 元素：纯黑底；荧光黄绿或品牌色；便利贴、贴纸式标签；全程字幕。
- 做法：口播视频当主轨，解释段整屏动画；贴纸跟着口播的词逐个弹出。
- 做偏：全程小窗或全程全屏；动画和口播的词对不上；黑底上只有一张小卡片（`video_qa.py` 报「画面空」）。

### 3. 2.5D 等轴科技插画
- 定义：等轴视角的积木小世界，扁平小人在上面把道理演出来，画面上字很少。
- 元素：亮色底；蓝紫为主、橙黄绿点缀的积木（每块三个面三档明度）；几何小人；连线、光点。
- 做法：等轴投影 `x' = (x − y)·cos30°，y' = (x + y)·sin30° − z`；道理靠搭建、拆开、连线、发光演出来。
- 做偏：画面中央一座浅色孤岛，四周大片空底、小人很小。积木要铺到画面边缘，镜头推近到正在演示的角色。

### 4. 科技玻璃拟态
- 定义：深蓝底上的半透明毛玻璃卡片、发光细线，讲到哪个词就点亮哪个东西。
- 元素：深蓝渐变 + 细网格；毛玻璃卡片（模糊 + 白色细边 + 高光）；青色发光线；数据标签。
- 做法：`backdrop-filter`；元素按配音的说话段落点亮。
- 做偏：到处霓虹；卡片同时出现；卡片小、留白大。

### 5. 撕纸拼贴绘本
- 定义：彩色手工纸一层层贴上去，纸边带白色撕边，有纤维和投影；不是扁平矢量。
- 元素：高饱和纸色块；6–10 像素白色锯齿撕边；轻投影；纸纤维纹理；圆头 Q 版小人。
- 做法：形状 = 锯齿多边形 + 白边 + 投影 + 纸纹贴图；动起来像纸片被拉动（轻旋转、弹跳）。
- 做偏：没有白边和纸纹，就成了普通矢量卡通。

### 6. 手绘墨线卡通
- 定义：粗细变化的毛笔墨线、分层明暗、纸纹笔触；不是干净的扁平矢量。
- 元素：暖色纸底；黑褐色墨线（起笔细、中段粗、收笔细，偶有飞白）；平涂加一两档阴影；胶片颗粒和暗角。
- 做法：角色写成一个绘制函数，所有镜头复用，造型统一；纸纹、颗粒叠最上层。
- 做偏：线宽一致、没有纸纹；角色每个镜头长得不一样。

### 7. 复古地图纪录片
- 定义：摊在木桌上的泛黄地图当主线，红铅笔现场画路线，老照片头像卡出场。
- 元素：泛黄纸、等高线、指北针、红蓝箭头、印章；台灯暖光、折痕、颗粒；宋体或仿宋。
- 做法：路线按时间一笔画出来，画完沿线标注再逐个弹出；每次回到地图都换景别（全图 → 某个村镇 → 贴近笔尖）。
- 做偏：干净的现代信息图地图；路线整条一下子出现；每次回到地图都是同一个景别。

### 8. 国风手绘动画
- 定义：颜料笔触、粗细不匀的墨线、水彩纸纹理，颜色素雅偏灰。
- 元素：低饱和青绿、赭石、墨色；云雾层次；远山、老树、小桥；留白。
- 做法：分层绘制 + 笔触纹理；季节用色调和天气粒子（花瓣、落叶、雪）。
- 做偏：颜色太鲜、太干净；变成三维游戏画面。

## 质感层：让「代码画的」不显得廉价

代码画的东西显得廉价，通常是只有形状、没有质感。风格要求里提到的每一种质感，都要在静帧上看得到，缩到 360 宽还认得出。

| 质感 | 做法 |
|---|---|
| 纸纹 | 预生成一张噪声纹理（两三层不同尺度 + 稀疏短纤维），`multiply` 叠最上层，透明度 0.15–0.35 |
| 撕纸边 | 边缘带种子的随机锯齿（每 6–12 像素一个点，振幅 3–8 像素），外圈白边加投影 |
| 毛笔墨线 | 按速度改线宽，每段 ±0.6 像素抖动，偶尔留飞白 |
| 颗粒 / 胶片 | 按帧序号做种子撒细颗粒（仍然是确定的），加暗角 |
| 投影和体积 | 偏移的深色投影，或边上一条亮边（轮廓光） |

随机一律用带种子的随机数，并在时间轴外预先生成好。同一帧渲两次必须一模一样，返工时才能只重渲那几秒。

## 自己写风格卡

- 风格名用标准叫法（「撕纸拼贴」「赛璐璐」「等轴插画」），不自造词。
- 元素清单要能在静帧上逐条检查。
- 必写一条「做偏」。
- 知名角色、精细人物，代码画常被嫌简陋：优先三维现成模型或生图素材，除非用户点名纯代码。
